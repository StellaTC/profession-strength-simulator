# 职业强度模拟器

macOS Apple Silicon 原生桌面战斗模拟器。当前版本 **0.4.10**，使用 Rust / egui，包含九职业模板、可编辑装备、全阵容搜索、历史报告和结果对比。

## 功能

- 水、火、自然、剑、锤、枪、弓、弩、盾，三档职业模板；支持重复职业、技能及光环分工。
- 星球和地牢的多地点、多难度任务队列，支持暂停、取消及断点续跑。
- 全量职业、普通技能及光环方案枚举；第一轮1小时，各职业前50名24小时复核，前10名进入多种子48小时终测。
- 咖啡和个人缺蓝食物调整仅在初筛比较，选中的配置带入后续阶段。
- EPH、队伍 DPS、同职业总 DPS、人数和人均 DPS；按实际装备提供武器特效分析。
- 中文／英文界面，官方游戏图标，所有展示数值最多两位小数。
- SQLite 本地保存；运行时无需联网或另行安装 Node。

## 构建

需要 macOS Apple Silicon、Rust stable、Node 22 和 npm。

```sh
npm ci
npm run adapter
zsh scripts/provision-runtime.sh
zsh scripts/package.sh
```

输出为 `outputs/职业强度模拟器.app`。发布时应使用可独立运行的 Apple Silicon Node；`provision-runtime.sh` 复制当前 PATH 中的 Node，不负责消除其外部动态库依赖。

游戏基础数据版本为 `v1.20260927.0`。游戏数据、预设、图标及字体包含在源码资源中；不包含用户数据库、遥测归档、运行时二进制、构建缓存和本机应用包。

## 验证

```sh
cargo test --release
cargo test --release --manifest-path engine/Cargo.toml --lib
```

`tests/` 包含三支匿名真实队伍的48小时回归、归因守恒、模板合法性、队列恢复和筛选流程测试。基准是本地已核对规则的快照，不是私人服务端的运行记录。`docs/` 保留各版本修复说明；最新版本将运行中的排行榜查询间隔调整为60秒，进度和断点仍按原间隔保存。

独立压力复测工具位于 `examples/memory_stress.rs`；它需要自行提供的任务断点和数据路径，仅写入指定的测试目录。

## 本地数据

用户数据保存在 `~/Library/Application Support/阵容战斗模拟器/`，应用改名后继续使用此位置以兼容历史结果。此目录不进入源码仓库。

开发与测试可用 `LINEUP_HOME` 指定隔离的数据目录，`LINEUP_RESOURCES` 指定资源目录。临时文件放 `work/`，交付物放 `outputs/`，二者均被 Git 忽略。
