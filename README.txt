阵容战斗模拟器 0.2.8（macOS Apple Silicon）

启动：双击 outputs/阵容战斗模拟器.app。已另放一份独立应用在 /Volumes/StellaSW/阵容战斗模拟器.app。
应用包含 Node 预处理运行时、角色适配器、Rust 战斗引擎和 v1.20260927.0 数据；无需安装 Node，无需联网，也不读取旧工程。

配置中心分“阵容配置 / 职业模板 / 装备库”三个独立区域。
职业模板：九职业 × 中级/高级/顶级三档。可编辑完整参数、复制到队伍、恢复内置模板。
可编辑装备库：进入“配置中心 → 装备库”。直接编辑中文战斗属性和每级强化加成；完整字段在“高级编辑”中。点击“保存装备属性，应用到模拟”，随后新模拟直接使用新属性。
可复制装备为独立自定义装备，保留原品。修改原装备会影响所有装备该物品的角色。恢复此装备内置属性可回退。

阵容配置：管理三人/五人阵容，允许重复职业。
模拟台：单独选择普通星球、地牢、T0～T5难度、时长和随机种子，再选择已保存阵容。每个成员点“编辑参数”可更换装备、强化、等级、技能、触发器、消耗品、房屋、神龛和成就。装备选择器包含自定义装备；也可以直接编辑角色 JSON。
选择装备库条目只是在编辑物品；要使用复制的新装备，需要在队员装备选择器中选中它。
保存多支阵容，或用带 schemaVersion 的 JSON 导入导出。支持原模拟器 v2 队伍/单角色以及公开角色资料格式，游戏基础数据接受完整 init_client_data 或 maps 信封。

阵容对比：默认D4 T1，使用约75%逻辑核心。普通目标按游戏sortIndex排列，只保留11个星球综合地图；另有4个地牢。界面使用原项目中文映射和游戏物品/技能图标，地图以地区精华或宝箱图标辅助识别。
固定项：所选档位的装备、各职业归档中最常见的完整食物搭配、各技能最常见的完整触发条件、该普通技能组合最常见的顺序。所有角色移除任务徽章。
咖啡只在第一轮4小时初筛选择，不额外增加外部阵容方案数。先使用暴击＋究极伤害主属性＋究极攻击（枪的伤害主属性为近战）。若任何个人死亡率严格大于2次/小时，按当前死亡最多且尚未调整者，将暴击替换为究极耐力，用同一种子重测，再检查下一人；每人最多换一次，换后仍超标会记录。首测不超标时，第三杯在究极攻击与物理迅捷／法系吟唱之间按职业比较，重复职业默认共用第三杯选择。比较过程出现个人超标也执行同样的耐力调整。按EPH、失败率、死亡率保留最佳配置，咖啡和调整记录存入SQLite，原样进入24/48小时复核，不再重新选择。幸运、经验咖啡全部排除。
普通技能：每职业使用率至少20%入池，严格超过99%必带，枚举4个普通技能槽的合法组合。同一阵容里的同职业共用普通技能组合和顺序。
特技：职业使用率≥20%的特技加上通用速度、守护、元素、物理、暴击光环；Insanity只允许水法。纯法系不带物理光环，纯物理不带元素光环。团队光环不重复；主属性对应职业优先，其次比较对应培养等级；最高者冲突则两种择一，不下放给次优队员。等级相同才保留分工。相同固定配置的队员互换携带者去重。不允许空特技槽；无法分工的职业组合排除。无敌属于自身特技，多个盾可各自携带。
标准模板枚举：三人职业池165种，全部可行，共63,602个完整方案；五人职业池1,287种，其中991种可行、296种无解，共769,904个完整方案。自定义模板会影响光环分工。
有限筛选：先用基准咖啡做4小时职业组合预览，再对全部完整方案各模拟4小时并选择咖啡；按队伍EPH取前50%各模拟24小时；从24小时结果按各职业取包含该职业的前20名，合并去重，最多180个方案。最终默认8个独立种子各模拟48小时，展示平均EPH和Student-t 95%置信区间。阶段内共同随机种子。跑完即结束，不再按8小时预算持续随机优化。完整枚举规则限定了范围，不代表所有可能装备、触发器的全局最优。
普通星球EPH=遭遇次数/总模拟小时。地牢EPH=成功通关次数/已结束尝试累计小时，团灭与重开等待计入，结尾未完成的尝试及尾部耗时排除。按平均EPH排名，持平比较失败率和死亡率；DPS、经验不参与EPH加权。职业榜可切换个人平均DPS比较，总榜可切换团队DPS比较。重复职业的个人DPS按成员平均。
所有候选以编号和统计分批写入本应用SQLite，入围列表在磁盘分页，完整方案按编号恢复，避免把数十万套完整配置同时放入内存。阶段进度显示本阶段候选数，最终候选不超过180个。
暂停和取消会停止当前模拟，完整候选已写入 SQLite。恢复时重跑被打断的候选，继续其余阶段。历史任务可从磁盘断点恢复。数据/模板/引擎版本不一致时须新建搜索。

结果分析：队员原始/重新归因 DPS，耗蓝与消耗品，普通/Boss阶段与各怪物，直接命中层数、伤害加权实时/DoT快照层数、满层率。完整 JSON 含输入配置、编译后场景、版本哈希与原始统计。
诅咒归因按本次时间线中有效叠层来源分摊。满层刷新不会重新拥有旧层；过期清空，DoT保留快照来源。自身贡献不向自己重复转移，队伍总伤害守恒。归因不预测移除弓后的队伍伤害。
多种子排行榜使用平均 EPH 和 Student-t 95% 置信区间。明细图显示首个种子，全部种子的完整结果保存在 seed_runs 中。

数据存储：~/Library/Application Support/阵容战斗模拟器/
- simulator.sqlite：模板修改、保存阵容、任务断点、结果。
- game-data.json：导入或修改后的本地属性库。
旧项目、旧 SQLite 和线上服务不修改。

开发构建：npm ci && npm run adapter；cargo test --release；cargo test --manifest-path engine/Cargo.toml --release --lib；./scripts/package.sh。
resources/runtime/node 是应用附带的 arm64 Node 22.23.0（构建时保留本机运行时副本）；主程序由 cargo 生成。
来源与验证：outputs/模板来源.json、outputs/基准验证.json、outputs/搜索生命周期验证.json，engine/UPSTREAM.md 与 docs/。


最新培养规则（2026-10-28）：顶级武器对应主属性170，按战斗经验分配表获得经验的其余副属性150；高级160/140，中级150/130。不参与该武器经验分配的属性维持原模板。枪将主、副属性的累计经验平均后反查等级：中级攻击/近战143、高级153、顶级163，经验余量见“枪经验均分验证.json”。技能、特技、强化档位保持80/50/+12、90/60/+14、100/70/+15。
武器特效：诅咒弓展示各队友转移绝对伤害、DPS和比例；裂空弩展示穿透触发次数、每次额外攻击/命中怪物数、额外直接伤害与个人/团队占比。另记录水法涟漪实际回蓝与冷却缩短、火法追加伤害、自然有效治疗、剑招架伤害、锤重试伤害、枪平均层数/满层时间、盾虚弱覆盖。最终结果合并全部种子统计，计数和绝对值按单次复核平均。归因与实际触发不等于移除武器后的反事实收益。

2026-10-29：三档九职业的27个内置预设，五项战斗神龛全部统一为5级。应用首次启动此版本时同步已有职业预设，仅更新神龛配置；用户修改过的装备、培养等级、技能保持原值。已经计算的历史结果保留原配置，新建比较使用更新后的预设。
